# NovaAI

NovaAI is an enterprise AI assistant built with modern AI technologies, featuring:

- 🤖 Conversational AI powered by Groq
- 🧠 Long-Term Memory
- 🎤 Voice Assistant (Speech-to-Text & Text-to-Speech)
- 📚 Retrieval-Augmented Generation (RAG)
- 🔐 JWT Authentication
- 💬 Persistent Conversation History
- ⚡ FastAPI Backend
- ⚛️ React + Vite Frontend

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router

### Backend
- FastAPI
- Python
- LangChain
- LangChain-Groq
- SQLite
- ChromaDB
- Redis/FakeRedis

## Features

- AI Chat
- User Authentication
- Conversation History
- Long-Term Memory
- Voice Intelligence
- Knowledge Base (RAG)
- Responsive Modern UI

## Getting Started

### Backend

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
